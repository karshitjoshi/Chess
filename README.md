# ♟️ Chess in C using Allegro

A simple, cross-platform chess game built with **C** and the **Allegro 5** library. This project serves as a practical dive into game development and GUI programming in C, supporting full chess rules in a minimalistic click-based interface.

https://github.com/user-attachments/assets/5cf2b19e-7178-42bb-89a2-3545703ddfb0

---

## ✨ Features

- 🧠 Full chess logic (legal moves, check, checkmate, castling, en passant, pawn promotion)
- 🖱️ Click-to-move interface with visual move highlighting
- 🎨 Basic piece rendering using external assets
- 🔁 Turn-based logic (White vs. Black)
- ⚙️ Cross-platform compatibility via Allegro

---

## 🛠️ Built With

- **Language:** C
- **Graphics/Input Engine:** [Allegro 5](https://liballeg.org/)
- **Compilation:** Bash script (for Linux/macOS); manual GCC command possible for Windows
- **OS Support:** Cross-platform (Linux, Windows, macOS)
